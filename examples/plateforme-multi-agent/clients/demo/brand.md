# Brand — Studio Demo (client fictif d'exemple)

- Nom : Studio Demo
- Activité : agence qui automatise la prospection des petites entreprises avec l'IA
- Promesse : « Vos rendez-vous commerciaux, sans y passer vos soirées. »
- Site / réseaux : LinkedIn, Instagram, YouTube

## Ton de voix
- Adresse : tutoiement
- Langue : français
- 3 adjectifs du ton : direct, concret, chaleureux
- On sonne comme : un pote entrepreneur qui a déjà fait l'erreur avant toi
- On ne sonne jamais comme : une plaquette corporate

## Interdictions (BLOQUANTES)
- Jargon banni : « synergie », « disruptif », « révolutionnaire », « game changer »
- Sujets interdits : promesses de revenus chiffrées garanties
- Concurrents à ne jamais citer : aucun nom de concurrent

- À éviter : robots humanoïdes, cerveaux lumineux, codes binaires
